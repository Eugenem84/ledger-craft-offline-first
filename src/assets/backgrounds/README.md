# Фоновые картинки специализаций

Сюда кладутся картинки-фоны рабочих профилей (правка владельца 17.09.2026).
Одна картинка — одна специализация: **имя файла = `preset_key`** из
`src/domain/presets/*.js`.

```
src/assets/backgrounds/
  bike.webp        # Ремонт велосипедов (#4caf50) — есть, картинка владельца
  auto.webp        # Автосервис      (#ff7043)
  hvac.webp        # Климат          (#42a5f5)
  aquarium.webp    # Аквариумы       (#26c6da)
  default.webp     # необязательная: профиль без пресета
```

Что происходит дальше: файлы подхватывает `src/services/backgroundAssets.js`
(`import.meta.glob`) — они попадают в бандл (работают офлайн и уезжают OTA-обновлением
веб-слоя), а `src/components/ui/LcAppBackground.vue` рисует картинку активного профиля под
интерфейсом. Ниша без файла — просто чёрный фон: это не ошибка, приложение выглядит как
раньше (сплошные поверхности).

**Правила и размеры** (полное ТЗ — `docs/UI.md` §7):

| Параметр | Значение |
|---|---|
| Формат | WebP (lossy, quality 88–90); PNG/JPEG тоже заработают — сконвертируем |
| Пропорции | **квадрат или шире 9:20** — тогда у картинки есть свой запас для параллакса и её не нужно увеличивать. Кадр ровно 9:20 тоже работает, но его придётся увеличить на ~16 % (теряется резкость и часть композиции) |
| Размер | 1024 × 1024 — допустимо, если картинка мягкая и тёмная (на телефоне она растягивается ~2.3×); для резкости — 2048 × 2048 или 2400 × 2400 |
| Вес | ≤ 300 КБ на файл (все четыре ≤ 1.2 МБ — это размер бандла) |
| Цвет | sRGB, 8 бит/канал, без прозрачности |
| Яркость | средняя ≤ 20 %, максимум в центре ≤ 40 % — карточки полупрозрачные, иначе тексту и жёлтому акценту не хватит контраста. Пример: `bike.webp` — средняя яркость 3 % |
| Композиция | портретный экран показывает **центральную полосу** картинки (у квадрата — ~45 % ширины), и при листании эта полоса едет на ±16 % ширины экрана. Сюжет держите в центре: гарантированно видно ~30 % ширины (квадрат) / ~72 % (кадр 9:20), края — запас под параллакс |
| Контент | тёмные мягкие тона, без текста, логотипов и «интерфейсных» элементов; края хорошо увести в чёрный |

Амплитуду параллакса и увеличение считает `backgroundLayout()` (`src/utils/tabSwipe.js`)
от реальных пропорций файла: амплитуда — от 8 % до 16 % ширины экрана (60 % свободного
запаса картинки), увеличение — только если запаса не хватает.
