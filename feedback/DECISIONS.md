# `DECISIONS.md` — журнал разбора отчётов (Фаза 14, задача 14.9)

Заполняется после каждой выгрузки (`npm run feedback:pull`): у каждого отчёта должен быть вердикт —
баг это или нет, и куда он ушёл. Персональные данные сюда **не** переносим (отчёты лежат в
`feedback/inbox/`, он в `.gitignore`); здесь только дата, короткая суть и решение.

| Дата       | Отчёт (`feedback/inbox/…`)                             | Вердикт | Куда ушло |
| ---------- | ------------------------------------------------------ | ------- | --------- |
| 13.09.2026 | _правило заведено вместе с Фазой 14; записей пока нет_ | —       | —         |

Формат вердикта: **баг** → ID задачи в `TODO.md` (с приоритетом и критерием «Готово»);
**не баг / предложение** → объяснение, почему не берём или куда отложили (по возможности ID задачи).
